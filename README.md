# HO ClipTrace

<img width="574" height="392" alt="K-007" src="https://github.com/user-attachments/assets/7207da2d-051a-4699-9831-4c119d838bb1" />

A lightweight Windows clipboard widget that remembers copied content together with its source information.

HO ClipTrace helps you quickly find copied text, images, files, and file paths, then reopen the original source when available.

## ✨ Features

* Save clipboard history
* Remember source information when available
* Support text, image, file, and file path records
* Reopen the original URL, file, folder, or app
* Quick popup with Ctrl + Win + V
* Exclude specific apps from tracking
* Auto start with Windows
* Multi-language UI support
* Local-only storage with no cloud sync or external upload
